# names.

A minimal, premium brand-name explorer for a creative technology company.

## What it does

- Presents a curated index of 24 names from the supplied naming document.
- Uses a black, white, and warm-paper visual system with editorial typography.
- Filters names by creative, technical, and global positioning.
- Opens a focused detail view for each name with meaning, recommended expression, rationale, and domain routes.

## Run locally

This is a dependency-free static site. Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deployment

The project is ready for Netlify as a static site. No build command or publish directory is required; the project root is the publish directory.
